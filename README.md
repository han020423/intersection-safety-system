# Intersection Safety System

교차로 안전 보조 시스템 프로젝트 레포지토리입니다.

## 프로젝트 목표
이 프로젝트의 목표는 교차로 주행 상황에서 보행자, 차량, 신호등, 횡단보도, 표지/표시 등의 정보를 인식하고,
**우회전 및 비보호좌회전 상황**에서 STOP / CAUTION / GO 판단을 수행하는 것입니다.

최종적으로는 다음 기능을 목표로 합니다.

- 교차로 위험 요소 인식
- 우회전 상황 판단
- 비보호좌회전 상황 판단
- 라즈베리파이 기반 경고 출력
- 위험 이벤트 서버 전송 및 저장
- 위험 발생 위치 지도 시각화

## 1차 구현 범위
현재 1차 구현 범위는 다음과 같습니다.

- 우회전 + 비보호좌회전 상황
- 보행자 / 차량 / 신호등 / 횡단보도 / 표지(또는 표시) 인지
- STOP / CAUTION / GO 판단
- LED 또는 디스플레이 기반 경고
- 위험 이벤트 로그 저장
- 지도 기반 위험 위치 표시

## 폴더 구조

- `docs/` : 프로젝트 문서
- `backend/` : Spring Boot 서버
- `ai/` : 학습 관련 코드 및 설정
- `edge/` : Raspberry Pi 추론 / FSM / 통신
- `data/` : 데이터 관리 설명
- `models/` : 모델 파일 관리 설명

## 개발 원칙

- 서버와 AI/임베디드 코드는 하나의 레포에서 관리한다.
- 대용량 데이터셋과 학습된 모델 파일은 Git에 올리지 않는다.
- 문서에서 정의한 event 형식, reasonCode, 시나리오 타입을 기준으로 맞춘다.
